# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting
(Security tab, "Report a vulnerability") or email m.cebic@web.de.

You get an acknowledgement within 7 days. This tool only reads project files and
runs the project's own ESLint, but a rule that suggests an insecure setting is a
vulnerability too, so report those as well.
